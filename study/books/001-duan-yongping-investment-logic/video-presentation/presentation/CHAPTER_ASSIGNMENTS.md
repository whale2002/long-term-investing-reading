## 01-coldopen — 别先看股价（已完成）

路径：`src/chapters/01-coldopen/`

1. 长期投资阅读分享。第一期。段永平投资问答录：投资逻辑篇。今天先聊一个核心。买股票就是买公司。
2. 大家好。从今天开始，我们做一个栏目。每一期，分享一本投资相关的书，或者一份重要资料。不抄结论。也不做买卖建议。重点是把里面能复用的判断框架讲清楚。第一期，我们先读《段永平投资问答录：投资逻辑篇》。它不讨论短期涨跌。重点是看他怎么理解公司、能力圈和少犯错。
3. 很多人学价值投资，第一步就走偏了。他们盯着股价。
4. 段永平反复提醒，别先看报价。先问一件事。你买的到底是什么？
5. 如果你买的是股票代码，那你会追涨杀跌。
6. 如果你买的是公司，你的注意力会变。你会看生意。看现金流。看它能不能活很久。
7. 所以今天这份分享的主线很简单。投资不是预测明天。

## 02-ownership-thesis — 买的是公司，不是报价

路径：`src/chapters/02-ownership-thesis/`
CSS 前缀：`.ot-`

1. 投资是在能力圈里，买入好公司的一部分。价格要合适。错误要少犯。这条线贯穿整本书。它让投资从报价回到资产。
2. 最难的地方，不是背下这句话。买股票就是买公司。这不是口号。它是行动约束。约束不稳，后面都会变形。这一点越早确认，后面越少返工。这一步别省。
3. 真正难的是市场大跌时，你还按这句话行动。别人质疑时，你也不乱。
4. 每次想买之前，先问三个问题。我真的懂这家公司吗？它未来能持续赚钱吗？这个价格，比别的机会更好吗？
5. 如果买入理由和这三个问题无关。比如图形好看。比如别人都在买。

## 03-right-things — 做对的事情在前

路径：`src/chapters/03-right-things/`
CSS 前缀：`.rt-`

1. 比如最近跌很多。那大概率已经不是投资了。
2. 段永平有一个区分很有用。做对的事情。和把事情做对。这两个顺序不能反。
3. 做对的事情，是先选方向。买公司。看现金流。
4. 留在能力圈。避开杠杆和做空。
5. 把事情做对，是在方向对之后。研究商业模式。理解护城河。看管理层。比较机会成本。

## 04-principles-stop-list — 原则和不为清单

路径：`src/chapters/04-principles-stop-list/`
CSS 前缀：`.ps-`

1. 如果方向错了，执行越努力越危险。你可以把财报看得很细。也可以把模型做得很漂亮。但买错东西，还是错。
2. 所以投资先要有原则。技巧排在后面。原则不稳，市场一晃，你就会找消息。找情绪。找别人替你判断。
3. 这也是不为清单的价值。它不是装保守。它是防止你一次出局。长期投资，先得活下来。
4. 这份清单可以很朴素。不做空。不用保证金融资。
5. 不碰看不懂的东西。不为了快去走捷径。

## 05-stop-boundary — 少动作与能力圈

路径：`src/chapters/05-stop-boundary/`
CSS 前缀：`.sb-`

1. 再加几条也很重要。不轻易扩大能力圈。不频繁决策。不做短期投机。不重仓脆弱现金流。
2. 很多错误不是因为人笨。是因为人太想快。想快，就容易借钱。想快，就容易越界。它能帮你少犯那种回不了头的错。大错少了，复利才有时间工作。它保护的不是某一次收益。它保护的是你的长期资格。
3. 一份好的不为清单，会让你少很多动作。少动作不是坏事。投资里很多时候，最值钱的动作就是不做。
4. 能力圈也一样。它不是你知道多少名词。它是你知道边界在哪里。
5. 知道不懂什么，比知道懂什么更难。

## 06-circle-business — 理解边界与好生意

路径：`src/chapters/06-circle-business/`
CSS 前缀：`.cb-`

1. 看懂一个生意，不靠临时刷资料。它来自长期经验。来自产品体验。来自行业理解。也来自反复验证。
2. 你可以问自己。我为什么比市场更懂它？我懂的是事实，还是故事？我能说清十年后的现金流吗？如果答案只是听来的，就还不算懂。听来的信心，经不起下跌。真正的理解，要经得起时间和报价一起拷问。
3. 还有一个更硬的问题。如果股价跌一半。我会更有信心。还是只剩恐惧？
4. 答不上来时，别急着证明自己。最好的动作通常是不做。不做，也是投资能力的一部分。
5. 段永平谈好公司，不只谈护城河。他把生意模式、护城河、企业文化放在一起看。单独讲护城河，很容易变成口号。

## 07-good-business — 好生意落到结果

路径：`src/chapters/07-good-business/`
CSS 前缀：`.gb-`

1. 好生意要能长期赚钱。赚钱不能太依赖刺激。不能太依赖高杠杆。
2. 客户还要愿意持续付费。
3. 产品或服务要有差异。公司赚到钱后，还要会分配。管理层和文化，也不能把好生意毁掉。
4. 护城河要落到结果上。现金流更稳。定价权更强。犯错概率更低。生命周期更长。
5. 所以看公司时，别只找一个漂亮词。要把生意、现金流、文化连起来看。连不起来，就先放下。

## 08-valuation — 估值是追问现金流

路径：`src/chapters/08-valuation/`
CSS 前缀：`.vl-`

1. 估值也是这样。未来现金流折现，不是让你算出神奇数字。它是一种追问方式。逼你把钱从哪里来想清楚。
2. 未来没人能精确预测。所以公式不是重点。重点是持续性。资本投入。还有钱怎样回到股东手里。
3. PE、PB、增长率、安全边际。这些都不是单独理由。
4. 它们只是工具。用来帮助你理解现金流和机会成本。
5. 段永平常说毛估估。这不是随便估。而是在看懂生意之后，判断一个大致区间。不追求小数点后的准确。

## 09-financial-filter — 财报是过滤器

路径：`src/chapters/09-financial-filter/`
CSS 前缀：`.ff-`

1. 真正难的地方，是看懂未来现金流。不是会不会套公式。公式很快。理解生意很慢。
2. 财报也别用错。财报一定要看。但它通常不是买入理由。它更像过滤器。
3. 你要用财报排除风险。负债是不是危险。净现金是不是真的。利润和现金流能不能对上。
4. 还要看开销是否合理。利润质量靠不靠谱。商誉、应收、存货里，有没有藏着麻烦。财报不能替你决定买什么。它只能提醒哪里危险。
5. 看完财报后，如果你更不喜欢这家公司。或者更看不懂。那就是重要信号。别硬把它解释成机会。

## 10-error-rate — 高尔夫与低错误率

路径：`src/chapters/10-error-rate/`
CSS 前缀：`.er-`

1. 财务分析的目标，不是复杂。是看清真实利润。看清现金流。看清负债。看清资本配置。
2. 段永平还用高尔夫讲投资。长期成绩不是靠神奇一杆。而是靠一杆一杆少犯错。投资也一样。
3. 不要因为一次赚钱，就觉得自己懂了。不要追求每次抓住机会。更不要让一次冒险毁掉长期积累。
4. 好的投资体系，应该让人睡得着。拿得住。也错得起。你不会因为一两天报价，就把系统全推翻。
5. 这里的关键不是更勇敢。而是更少犯大错。长期投资的敌人，常常不是慢。是被一次错误清零。

## 11-active-index — 主动投资的门槛

路径：`src/chapters/11-active-index/`
CSS 前缀：`.ai-`

1. 所以普通人不一定适合直接买股票。这句话很重要。它不是打击人。它是在尊重主动投资的难度。
2. 主动投资要求很高。你要看懂公司。能承受长期波动。有独立判断。还要知道什么时候不动。
3. 如果这些条件不具备。指数基金可能更诚实。尤其是你承认自己看不懂的时候。这不是退步。
4. 承认不适合主动选股，本身就是能力圈。你知道边界。你也就少了很多无效动作。
5. 还有一块别漏。宏观要理解。但别沉迷短期预测。

## 12-market-method — 别让市场替你判断

路径：`src/chapters/12-market-method/`
CSS 前缀：`.mm-`

1. 牛熊也要尊重。但行情不能替代公司判断。
2. 衍生品和套利，看起来很聪明。可一旦超出能力圈。它们会把你带到不懂的地方。
3. 平常心不是装淡定。是你的投资体系，能让你不被市场牵着走。
4. 你可以理解环境。但不要让环境替你下判断。判断还是回到公司和现金流。
5. 今天会看到三个案例。茅台、网易、苹果。重点不是让你照着买。而是看他怎样判断自己懂。

## 13-cases — 案例不是持仓清单

路径：`src/chapters/13-cases/`
CSS 前缀：`.cs-`

1. 茅台对应强品牌。强需求。定价权。还有稳定现金流。它展示的是好生意的形态。
2. 网易对应行业经验。如果你真懂游戏生意。你可能看见别人忽略的现金流。但前提仍然是你懂。
3. 苹果对应产品和生态。消费电子经验，帮助理解用户黏性。也帮助理解品牌和资本配置。
4. 三个案例的共同点，不是公司名字。而是只在自己真正懂的地方下重注。这比抄持仓重要得多。案例不要看成标准答案。它们是在演示框架怎么落地。不是告诉你今天该买谁。
5. 落到实践，可以先用五问框架。这家公司卖什么？客户为什么持续买？

## 14-five-questions — 研究前五问

路径：`src/chapters/14-five-questions/`
CSS 前缀：`.fq-`

1. 长期赚钱靠什么？
2. 它的钱是运气、周期、补贴、杠杆。还是真实竞争力？未来现金流大概从哪里来？能持续多久？
3. 管理层会怎么处理赚到的钱？当前价格和其他机会相比，够不够好？这些问题答不清，就别急。
4. 安全边际也有三层。不是只有价格折扣。第一层，是理解边际。我真的懂这个生意。
5. 第二层，是经营边际。公司有好生意。有护城河。文化不容易乱来。

## 15-price-buy-sell — 价格边际与买卖

路径：`src/chapters/15-price-buy-sell/`
CSS 前缀：`.pb-`

1. 第三层，才是价格边际。价格相对未来现金流和机会成本，足够合适。只便宜但不懂，不安全。
2. 买入也可以反过来看。不要因为最近跌很多而买。不要因为很多人推荐而买。不要因为PE低就买。也不要因为宏观故事顺耳。
3. 你买，是因为看懂了公司。未来现金流有把握。价格相对机会成本合适。就算市场长期不开门，也愿意拥有它。
4. 卖出通常也不是因为波动。一种情况，是原判断错了。一种是公司变了。还有一种，是机会成本变了。
5. 如果只是短期恐慌。或者别人观点变了。那不自动构成卖出理由。还是要回到公司和现金流。

## 16-practice-closing — 练习与收束

路径：`src/chapters/16-practice-closing/`
CSS 前缀：`.pc-`

1. 看完这条，别急着找下一本。先写一页自己的不为清单。只写五条也行。但要真能执行。
2. 再选一家你熟悉的公司。用五问框架走一遍。答不上来的地方，标出来。那就是你的边界。
3. 还可以挑一份财报。只看四件事。负债。现金流。真实利润。资本配置。
4. 再提醒一句。这不是买卖建议。也不是让你抄段永平持仓。学的是排除、等待和下注方式。写下来，才能在下次波动时拿出来核对。不写下来，波动时容易重新编理由。
5. 投资只需要富一次。前提是别先把自己淘汰。把能不做的事写清楚。再慢慢学习做什么。
6. 这就是今天的分享。投资不需要每天都有动作。更重要的是知道什么不该做。
