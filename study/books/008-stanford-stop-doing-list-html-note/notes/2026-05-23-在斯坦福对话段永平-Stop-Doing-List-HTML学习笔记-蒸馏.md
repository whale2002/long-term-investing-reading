## 一句话

Stop Doing List 的核心不是“少做事”，而是用清晰的是非边界抵抗短期诱惑，把时间和资源留给长期正确的事。

## 核心观点

### 1. 不做错事，比努力做事更靠前

- 原文/原笔记观点：段永平说“不做的事情更重要”，因为聚焦才能做长期正确的事情；很多人不是判断不了对错，而是明知错误仍被短期诱惑拉走。
- Agent 的解释：这不是效率问题，而是方向问题。方向错时，执行力越强，损失越大；方向对时，执行力才有复利。
- 对用户的学习启发：研究投资时，先写“我绝不做什么”，再写“我想做什么”。这能减少被热点、行情和他人观点牵着走。

### 2. Stop Doing List 是长期主义的护栏

- 原文/原笔记观点：文章把 Stop Doing List 和长期思维联系在一起，强调相信时间的力量，能用十年以上视角看待波动。
- Agent 的解释：长期主义不能只靠意志力。真正能穿越波动的，是事先设好的边界，例如不懂不投、不用杠杆、不做短期投机。
- 对用户的学习启发：长期投资不是“拿得久”本身，而是只拿那些自己理解、能承受、并且没有触碰不为清单的东西。

### 3. 清单来自错误和取舍，不是一次写完

- 原文/原笔记观点：段永平说这个 list 是一条条攒出来的，来自对成功经验的扬弃和对错误经历的总结；有时放弃过去的成功经验很难。
- Agent 的解释：Stop Doing List 不是静态格言，而是复盘系统。每次因为诱惑、面子、侥幸或不懂装懂而吃亏，都应该沉淀为新的边界。
- 对用户的学习启发：可以建立一份个人投资“不为清单”，每次复盘只问两个问题：这次错在认知、纪律，还是边界不清？

### 4. 能力圈的关键是诚实承认边界

- 原文/原笔记观点：段永平强调不懂不做、不熟不投，不要盲目扩充能力圈；能力圈不是画个圈，而是“知之为知之，不知为不知”。
- Agent 的解释：能力圈不是知识覆盖面，而是可验证的判断力。看过资料、听过故事、熟悉产品，都不等于理解商业模式和现金流。
- 对用户的学习启发：判断一个公司是否在能力圈内，不要问“我知道多少”，而要问“如果价格大跌，我能否用生意逻辑重新说明它的价值”。

### 5. 投资要回到生意、人和价格

- 原文/原笔记观点：段永平把好的投资标的概括为 right business、right people、right price，并强调能拿十年以上的公司才值得认真看。
- Agent 的解释：这三个词分别对应现金流来源、组织和文化、以及相对长期价值的价格。价格不是不重要，而是不能脱离生意和人单独判断。
- 对用户的学习启发：研究公司时，把财务指标放在“生意如何赚钱、谁在经营、价格是否留有余地”之后，而不是反过来。

### 6. 好公司首先是好产品和好文化

- 原文/原笔记观点：交流中多次强调产品是本质，营销不是本质；企业文化包括使命、愿景和核心价值观，价值观不匹配的人要淘汰。
- Agent 的解释：产品决定用户是否真实需要，文化决定组织会不会长期做正确取舍。营销能放大结果，但很难替代产品和文化。
- 对用户的学习启发：看公司不要只看增长叙事，要追问用户为什么持续买、公司为什么能持续做出好产品、组织是否会为了短期利益伤害长期信任。

### 7. 现金和低杠杆是生存能力

- 原文/原笔记观点：段永平提到不做长期有息贷款、不用 margin、不做空，认为这样在危机中才有最大生存机会。
- Agent 的解释：这背后是时间方向的问题。高杠杆、做空和短期投机都容易让时间变成敌人；现金和低杠杆让时间更可能成为朋友。
- 对用户的学习启发：在学习投资时，不要只研究收益率，也要研究“什么情况下会被迫出局”。长期复利的前提是避免致命错误。

### 8. 案例是理念载体，不是可复制答案

- 原文/原笔记观点：文章提到 Apple、网易、特斯拉、拼多多、OPPO、vivo 等案例，也记录了段永平当时的具体看法。
- Agent 的解释：这些案例发生在 2018 年语境中，核心价值是展示段永平如何用能力圈、商业模式、文化和不为清单做判断，而不是提供今天的投资结论。
- 对用户的学习启发：读案例时，不要复制标的，要复制提问方式：他为什么懂？他看重什么？他排除了什么？如果条件变了，判断会怎么变？

## 概念解释

### Stop Doing List

- 原文/原笔记观点：发现错了就要停，越早停止，代价越小；它不是技巧或公式，而是一种思维方式。
- Agent 的解释：Stop Doing List 是把价值观和风险控制写成负面边界，帮助人在诱惑出现时不临场发挥。
- 对用户的学习启发：一份有效的不为清单要具体到行为，例如“不用融资杠杆”“不做看不懂现金流的资产”“不因短期涨跌改变研究结论”。

### 做对的事与把事情做对

- 原文/原笔记观点：文章多次使用 Do right thing, do things right；Stop Doing List 主要服务于“做对的事”。
- Agent 的解释：做对的事是方向和原则，把事情做对是能力和执行。方向错误时，能力会变成放大器。
- 对用户的学习启发：每次研究前先判断“这类事该不该做”，再研究“这件事怎么做得更好”。

### 能力圈

- 原文/原笔记观点：不懂不做、不熟不投；能力圈来自对自己诚实。
- Agent 的解释：能力圈不是舒适区，也不是永久边界；它可以扩大，但只能通过长期学习、实践和验证慢慢扩大。
- 对用户的学习启发：能力圈笔记应同时记录“我懂什么”和“我不懂什么”，后者更能保护本金。

### Right Business、Right People、Right Price

- 原文/原笔记观点：对的生意、对的人、对的价格，是段永平归纳的投资三要素。
- Agent 的解释：对的生意看商业模式和现金流，对的人看创始人、团队和文化，对的价格看长期回报与机会成本。
- 对用户的学习启发：不要把“好公司”直接等同于“好投资”。即使研究对象很好，也需要问价格和机会成本。

### 平常心与本分

- 原文/原笔记观点：平常心是 rational，是回到事物本原；本分和诚信贯穿做人、做企业和投资。
- Agent 的解释：平常心不是情绪麻木，而是在关键时候不偏离事实和原则。本分不是保守，而是不占便宜、不骗人、不走捷径。
- 对用户的学习启发：投资研究里最难的不是知识点，而是能否在压力和诱惑下保持理性。

### 敢为天下后，后中争先

- 原文/原笔记观点：段永平解释，敢为天下后指产品类别上不盲目抢先，后中争先指满足已被验证的需求并做得更好。
- Agent 的解释：这是一种降低需求预测错误率的方法。它不追逐“第一个”，而重视“是否真的做对、做透”。
- 对用户的学习启发：看企业创新时，不只问它是不是最早，还要问需求是否真实、产品是否更好、组织是否能长期改进。

## 投资框架

### 1. 先定不为清单

学习版清单可以先写成：

- 不做看不懂商业模式和现金流的投资。
- 不用融资杠杆，不把自己置于被迫卖出的处境。
- 不做短期投机来满足手痒或娱乐心态。
- 不做空长期好公司。
- 不因为别人赚钱就扩大自己的能力圈。
- 不频繁决策，不用交易次数制造勤奋感。
- 不用宏观、热点或价格波动替代公司研究。

### 2. 再看生意

研究一个生意时，先问：

- 它卖什么，用户为什么持续买？
- 它的产品或服务有没有真实差异化？
- 它的利润来自用户价值，还是来自短期补贴、价格战或资本市场情绪？
- 它能不能长期产生现金流？
- 行业变化会强化它，还是削弱它？

### 3. 再看人和文化

重点看：

- 创始人和管理层是否诚实、理性、尊重用户。
- 企业文化是否允许长期做正确取舍。
- 公司是否为了短期收入牺牲产品、口碑或信任。
- 组织是否能筛选合适的人，而不只是合格的人。

### 4. 最后看价格

价格问题不应简化为“便宜不便宜”，而应拆成：

- 如果站在十年维度，当前价格隐含了什么预期？
- 未来现金流的大致来源是否清楚？
- 这笔投资相对其他自己能理解的机会是否足够好？
- 如果判断错了，损失边界在哪里？

### 5. 持有和卖出的原则

从本文抽出的学习框架是：

- 如果仍然是对的生意、对的人、对的价格，短期波动本身不是卖出理由。
- 如果盈利能力、文化、商业模式或自己的理解发生变化，要重新评估。
- 如果出现更懂、更有把握、价格更合适的机会，可以比较机会成本。
- 所有具体公司案例都只作方法学习，不构成买入、卖出或持有建议。

## 可执行清单

1. 写一页个人 Stop Doing List，先列 5 条最容易犯的错：例如追热点、听消息、频繁交易、看不懂也买、用短期价格验证自己。
2. 每研究一家公司，先写“我为什么可能不该研究它”，再写投资理由。
3. 建一张能力圈表：左列写“能解释清楚的生意”，右列写“目前看不懂的生意”，每月更新一次。
4. 做案例复盘时，只提炼问题和框架，不抄具体标的。
5. 对任何“好公司”结论补三句话：好在哪里、可能坏在哪里、什么价格或条件下我会承认自己看错。
6. 记录“未行动日志”：哪些机会因为不懂、太贵、边界不清而放弃；长期看这些放弃是否保护了自己。
7. 读巴菲特股东信或段永平问答时，把金句改写成自己的检查问题，而不是只收藏原句。

## 易误解点

1. Stop Doing List 不是消极不做事。它的目标是把资源留给真正该做的事。
2. “长期持有”不是任何东西都硬扛。前提是生意、人、价格和自己的理解仍然成立。
3. “好公司长期不贵”不能理解成任何价格都可以买。原文仍然保留了 right price 这个条件。
4. “不懂不做”不是停止学习，而是在理解成熟之前不下重注。
5. “危机是机会”只对准备充分、现金流稳、负债低、看得懂的人更可能成立；对脆弱系统，危机首先是风险。
6. 文中的 Apple、网易、特斯拉、拼多多等判断属于 2018 年交流语境，不能直接外推为今天的投资结论。
7. “AI 价值投资比不过人、投机人比不过机器”是原文观点，适合理解段永平对投资和投机的区分，不应简化为对所有量化方法的否定。

## 待追问问题

1. 我的个人 Stop Doing List 里，哪三条最能减少致命错误？
2. 如何判断一家公司是真的产品好，而不是营销强？
3. 能力圈从“不懂”到“懂”，需要哪些可验证证据？
4. 研究企业文化时，除了创始人访谈，还能从哪些行为和数据侧面验证？
5. “对的价格”怎样和机会成本结合，而不是只看估值倍数？
6. 如果长期观点和短期市场强烈冲突，什么证据能说明该坚持，什么证据说明该停止？
7. 对普通投资者来说，主动选股和指数化投资的边界应该如何划分？
