# 长期投资阅读分享

这个仓库用于把投资相关书籍、文章和资料逐步蒸馏成可复习的学习材料。

当前重点围绕段永平的投资与商业理念。仓库内容只用于学习、复盘和框架提炼，不构成任何买卖建议。

## 目录

```text
materials/  原始资料与封面素材
study/       蒸馏后的学习笔记和中间文本缓存
tools/       辅助脚本
AGENTS.md    Agent 协作规则
```

## 当前进度

学习索引见 [study/INDEX.md](study/INDEX.md)。

## 说明

- 原始资料保留在 `materials/`，蒸馏结果保留在 `study/`。
- 每次只围绕一个明确来源文件处理，避免一次性混合多个资料。
- 输出重点是投资原则、研究框架和学习启发，不提供具体股票或资产的投资结论。
